# Code of Conduct

## Our standard

Contributors and maintainers are expected to be respectful, constructive, and
welcoming. Harassment, discrimination, personal attacks, doxxing, and deliberate
publication of private information are not acceptable.

## Enforcement

Report unacceptable behavior privately through the maintainer's GitHub profile.
Reports will be reviewed and handled in good faith. Do not include unrelated
secrets or personal data in a report.
