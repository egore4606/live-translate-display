# Security policy

## Supported versions

This project is a small, actively maintained application. Security fixes are
made against the latest `main` branch. There are no separately supported
release branches yet.

## Reporting a vulnerability

Please do not open a public issue for an unpatched vulnerability.

Use GitHub's private vulnerability reporting feature on this repository when it
is enabled. If that feature is unavailable, contact the maintainer privately
through the GitHub profile associated with this repository and include:

- a clear description and affected file or endpoint;
- reproducible steps or a minimal proof of concept;
- the impact and any required conditions;
- a suggested mitigation, if known.

Do not include API keys, private recordings, cookies, personal data, or server
credentials in reports. Redact sensitive values before attaching logs.

The project is not a security-certified service. The public demo should not be
used for confidential presentations; self-host the relay and use a dedicated,
restricted Gemini API key for sensitive material.
